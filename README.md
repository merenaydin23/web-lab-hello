# Web LAB Projesi (LAB-1 / LAB-2 / LAB-3 / LAB-4 / LAB-5 / LAB-6 - Ara Checkpoint #1)

## Hakkında
Bu repo, **Web Tasarımı ve Programlama** dersi kapsamında **Vite + React + TypeScript** kullanılarak geliştirilmiş bir portfolyo uygulamasıdır. 

- **LAB-1**: Ortam kurulumu, Git iş akışı, kişisel bilgilerin eklenmesi
- **LAB-2**: Semantik HTML, erişilebilirlik (a11y), iletişim formu
- **LAB-3**: Modern CSS, responsive layout (Flex/Grid), design tokens, ekran görüntüleri
- **LAB-4**: Tailwind CSS Entegrasyonu, Utility-first CSS, Component Yaklaşımı, Dark Mode, UI Kit
- **LAB-5**: Modern JavaScript/TypeScript Temelleri, ESModules, DOM yerine State Mantığı, Fetch API ve Filtreleme/Sıralama İşlemleri
- **LAB-6**: React Temelleri (Component Mimarisi, Props/State, useMemo, Controlled Forms, List Rendering) ve **Ara Checkpoint #1**

## Ara Checkpoint #1 Görevleri (Tamamlananlar)
- [x] **Component Mimarisi**: Uygulama atomik bileşenlere (Header, Hero, ProjectList, Card, ContactForm vb.) bölündü.
- [x] **Props & State**: Veri akışı `props` ile sağlandı, durum yönetimi `useState` ile yapıldı.
- [x] **useMemo Optimizasyonu**: Proje filtreleme ve sıralama işlemleri `useMemo` ile optimize edildi.
- [x] **Controlled Form**: İletişim formu React state ile kontrol edildi, detaylı doğrulama (validation) eklendi.
- [x] **Liste Render & Key**: Projeler `.map()` ile listelendi ve benzersiz `key`ler kullanıldı.
- [x] **Fetch API**: Veriler asenkron olarak `public/data/projects.json` dosyasından çekildi.
- [x] **TypeScript**: `any` tipi kullanılmadan tüm veri modelleri ve prop tipleri tanımlandı.
- [x] **Responsive Tasarım**: Mobil, tablet ve masaüstü görünümleri için Tailwind CSS ile tam uyumluluk sağlandı.
- [x] **Git İş Akışı**: Feature branch (`feature/checkpoint-1`) kullanılarak adımlı commitler atıldı.
